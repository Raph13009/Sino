# OPOPA — Premium Design Direction (Revised)

**Status:** Approved — Phase 3 rollout on `design/premium-homepage-poc`  
**Primary benchmarks:** [Kearney.com](https://www.kearney.com/) (editorial) + [Pretto.fr](https://www.pretto.fr/) (floating glass nav)  
**Constraints:** EN/ZH copy, SEO, URLs, schema, forms, analytics immutable. Logo + signature red retained.

## Ambition

Not a polish of the current token set. Rebuild the visual interface so OPOPA reads as a **contemporary international advisory firm** with an industrial China–Europe identity — not a SaaS landing page.

## What we take from Kearney (art direction, not copy)

1. **Photography as the plane** — full-bleed heroes and mid-page visual bands; text rides the image.
2. **Air and institutional chrome** — tall, quiet header; sparse nav; thin hairlines.
3. **Editorial hierarchy** — large display type, short supporting lines, clear primary CTA as ghost or solid, never a “product card.”
4. **Dynamic page rhythm** — alternate immersive media sections with typographic / metric bands.
5. **Almost no rectangular cards** — structure via whitespace, rules, overlays, and asymmetry.
6. **Human / real-world imagery** — for OPOPA: industrial facilities, engineers, infrastructure (not abstract fluid art).

### Palette (homepage POC)

- **Ink:** `#121417` — near-black charcoal (replaces navy-leaning ink)
- **Paper:** `#F3F0E8` — warm paper (light editorial bands)
- **Snow:** `#FAFAF8` — clean light surface
- **Steel:** `#5C6168` — secondary text
- **Accent:** `#B01E28` — signature red (scarce)
- **Ink wash overlays:** black at 35–55% over photography for type legibility

### Typography

- Display: Inter Tight, **much larger** (hero clamp ~3.5–5.5rem), weight 500, tracking −0.03em
- Body: Inter 17–18px / 1.6
- CJK: Noto Sans SC unchanged
- Default **left** alignment; overlays use light type on dark media

### Layout principles

- Max content width ~1320–1400px; **full-bleed media escapes the container**
- Section rhythm: immersive band → editorial band → metric/proof → immersive → method → CTA
- Radius: **0–2px** (essentially square)
- Borders: hairline only when structuring lists; no card chrome
- Buttons: solid ink or ghost-on-dark; tertiary text+arrow

### Motion

- Header: full-bleed immersive → floating frosted glass pill on scroll (Pretto-like)
- Sections: subtle fade/rise on enter (150–400ms)
- Links: arrow translate 4–6px
- Image tiles/cards: slow scale on hover
- No generic SaaS card lift/shadow as identity

### Homepage architecture (visual, copy unchanged)

1. Immersive header over hero → floating glass bar on scroll  
2. Full-bleed industrial hero + overlay type + CTAs  
3. Services as large photo editorial cards (entirely clickable)  
4. Proof metrics as monumental figures on ink  
5. Use case as asymmetric image/text + metric band  
6. Industries-fit as photographic mosaic (non-linked labels)  
7. Context as immersive full-bleed overlay  
8. Why as sticky intro + editorial tile grid  
9. Industries as flush linked image mosaic  
10. Method as dark step grid  
11. Insight teaser (editorial split)  
12. Full-bleed dark final CTA  
13. Quiet institutional footer  

## Site-wide rollout

Shared glass header/footer + display typography + editorial service/industry cards applied across hubs and templates. Individual service pages keep structure/content; chrome inherits the system.
